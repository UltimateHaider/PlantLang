# 🌿 PlantLang — Chloroplast Complete Engine v0.17.0-Core

PlantLang is a structural, strongly-typed, natural-punctuation programming language engineered specifically for the AI-driven development era. Its primary architectural philosophy is to guarantee that source code generated by Large Language Models (LLMs) remains completely deterministic, structurally unambiguous, and deeply human-auditable. By eliminating traditional curly braces {} and non-visible tab-based indentations, PlantLang introduces an explicit Numerical Depth Matrix Tracking Engine coupled with a high-performance synchronous execution floor and compiler-grade terminal diagnostics.

## 🏗️ Technical Specifications & Architecture
* Pipeline: [Source Code] ➔ Tokenizer ➔ Parser ➔ AST ➔ SymbolPass ➔ evaluateNode.
* Execution Model: Synchronous, deterministic, block-scoped soil sandboxing.
* Memory Management: Automatic scoped-soil isolation, eliminating global state leaks.
* Syntax Enforcement: Numerical Depth Matrix (1\, 2\, 3\) replaces block-braces.
* Diagnostic Engine: Native visual caret (^) logging for syntax violation mapping.

## ✨ Core Philosophy & Features
* Code Depth (No Braces): Every block begins with an explicit depth number (1\, 2\). Eliminates ambiguity.
* Natural Punctuation: Statements end with a period (.), continuations with a comma (,).
* LISTEN BRANCH: Native HTTP server construct managing routing and JSON payload parsing.
* HARVEST: Synchronous background-threaded streaming that avoids event-loop blocking.
* BRAID: Dynamic collection merging and zip-stream key/value mapping.
* WHENEVER: Reactive data state watching bound directly to AST evaluation.
* SPECIES/BLOOM: Full OO-ecosystem with inheritance, method overriding, and state isolation.
* VERIFY/SUITE: First-class native assertion framework for automated regression testing.

## 📦 Core Enhancements (v0.17.0)
* Dynamic Symbol Pass: True two-pass design (register declarations ➔ sequential execution), enabling safe forward-referencing of actions and constants.
* Polymorphic Execution: The engine seamlessly bridges legacy string-record execution with modern typed-AST execution nodes.
* Diagnostic Backfilling: Deep-trace error reporting ensures uncaught exceptions in inner-AST blocks report correct source-file coordinates.
